개인정보 처리방침

시행일: 2026년 11월 13일

1. 작성한 기록

일기 제목과 본문, 선택한 사진의 사본, 연습 기록과 깃발은 사용자의 기기에 보관됩니다. 앱 운영자는 이 기록을 서버로 전송받거나 수집하지 않습니다. 앱에는 회원가입, 광고, 사용자 추적 또는 외부 분석 SDK가 없습니다.

2. 사진과 음성

사용자가 직접 선택한 사진만 일기에 추가합니다. 앱에서 사진을 삭제해도 사진 보관함의 원본은 삭제하지 않습니다. 영어 읽기는 기기의 음성 읽기 기능을 사용하며, 마이크 녹음이나 음성 인식은 하지 않습니다.

3. 보관과 삭제

기록은 사용자가 내용을 변경하거나 앱을 삭제할 때까지 기기에 남습니다. 기록 내보내기는 사용자가 선택한 위치나 앱으로 사본을 전달하는 동작입니다. 내보낸 파일과 기기 백업 사본은 사용자가 해당 서비스나 기기 설정에서 별도로 관리해야 합니다. 기기 백업에는 Apple의 정책과 사용자의 설정이 적용됩니다.

4. 문의

고객지원 이메일로 문의하면 보낸 이메일 주소와 문의 내용이 답변을 위해 처리됩니다. 문의에 개인 일기나 사진을 첨부할 필요는 없습니다. 문의 내용의 삭제를 원하면 같은 주소로 요청해 주세요.

5. 안내 웹페이지

이 안내 페이지에는 광고, 방문자 분석 도구나 추적 스크립트를 넣지 않았습니다. 페이지 제공을 위해 GitHub Pages를 이용하며, 웹페이지 접속과 관련한 정보는 GitHub의 개인정보 처리방침을 따릅니다.
